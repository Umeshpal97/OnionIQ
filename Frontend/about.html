ABOUT THE PROJECT

About OnionIQ

A digital platform for AI-assisted onion quality assessment and grading.

🧅

Smarter Onion Quality Assessment

OnionIQ is designed to make onion quality assessment faster, more consistent and easier to document using image-based AI analysis.

Instead of relying only on manual visual inspection, the platform provides a digital assessment workflow that can generate quality scores, grades and recommendations.

KEY FEATURES

What OnionIQ provides

📷

Image Assessment

Capture an onion image using the camera or select one from the device gallery.

🤖

AI Analysis

Analyze visual characteristics of the onion batch and generate an assessment.

📊

Digital Grading

View quality score, grade and important assessment parameters digitally.

📄

Digital Report

Generate a PDF report containing the assessment details and result.
